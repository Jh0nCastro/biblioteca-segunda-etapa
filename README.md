# Biblioteca — entregas da 2ª etapa

Atividades progressivas de Python e Flask, organizadas em pastas independentes:

1. `01_flask_2`: API CRUD com persistência em JSON;
2. `02_jinja2`: página inicial e listagem em tabela;
3. `03_formularios`: formulário de cadastro de livros;
4. `04_formulario_update`: formulário de atualização;
5. `05_sqlalchemy`: CRUD completo com Flask-SQLAlchemy, SQLite e API JSON.

Cada pasta contém seu próprio `README.md` e `requirements.txt`.
